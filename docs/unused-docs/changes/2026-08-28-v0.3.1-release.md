# Handoff Note

- Date: 2026-08-28
- Agent: Code
- Topic: v0.3.1 release — repair a published release with no assets

## Summary

`v0.3.1` had already been tagged, pushed and published as "Timer Functioning
Enhancements", but the release page carried **zero assets**. Both build jobs
succeeded; the `publish` job failed on one step:

```
error: CHANGELOG.md has no section for 'v0.3.1'. Available: ['Unreleased', '0.3.0', '0.2.0']
```

The tag was pushed before the changelog was versioned, and
`tools/extract_release_notes.py` refuses to invent a section rather than
publishing an empty release body — which is why the failure was loud and the
release stayed empty instead of shipping unlabelled binaries.

Fixed by doing what the 0.3.0 handoff note records: version the changelog, bump
the package version, then move the tag onto that commit so the assets and the tag
name point at the same source.

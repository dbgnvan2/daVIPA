**Date:** 2026-11-18 · **Branch:** `main` · **Range:** `868466e..HEAD`

Filed because three things here are measurements, not decisions, and a commit
message is the wrong place for them.

`main` was red from 2026-11-14 (`4a63a0a`) through 21 CI runs and the v0.3.5
and v0.3.6 releases. Last green: `bab5d5a`, 2026-11-14 15:04.

## TST-A2, filed and withdrawn on the same day

Filed as adjacent and deferred, then "closed" by adding a two-line guard to
each resize file, then **withdrawn**: the guard already existed, and the
filing was wrong.

`tests/test_list_resize_principles.py::test_lrpm11_the_row_wraps_only_below_the_minimum_fit`
does `fit(min_one_row_px())` / `assert not wrapped`, and more besides -- that
`min_one_row_px() < one_row_px()`, that the filters' drawn widths really do
shrink on the way down, and that one pixel lower wraps. It is parametrized
over every screen with filters, the Completed screen and the Scheduler
included. Under the reverted threshold it fails on 5 parametrizations
(measured 2026-11-18).

The mistake was the scope of the measurement, not the mutation. "All 131
tests in `tests/test_list_screen_resize.py` and
`tests/test_screen_resize_spc.py` stayed green" is true, and it was taken as
evidence of a gap without checking `tests/test_list_resize_principles.py` --
the file that owns the criterion, named in the very commit (`c73f225`) the
investigation started from. A mutation measured over a chosen subset says
nothing about the suite; the subset has to be justified, and this one was
chosen because the failing tests lived there.

Both added guards are reverted. Two of the four parametrizations in the list
file were vacuous anyway, Today and Projects having no filters, so
`min_one_row_px() == one_row_px()` there.

## One premise left unforced on purpose

`tests/test_plan_screen_week.py:463` asserts a week total is wider than
`WEEK_COLUMN_WIDTH_PX` (40). That is the case the test guards, so forcing it
would hide it. The margin is **not** measured: the 86 and 148 readings taken
while fixing the floor test are both the monkeypatched floor, so they only
bound the real text at 86. It sits somewhere in 41..86px. Carried as TST-A1.
